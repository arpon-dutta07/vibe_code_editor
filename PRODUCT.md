# Product

## Register

product

## Users

Developers building and shipping software: solo developers who want AI assistance in a browser-native editor, small teams collaborating on code in real time, enterprise organizations needing self-hosted deployment, and students learning through code. Context: active coding session, task-driven, low patience for decoration. They judge a tool by how fast it disappears into the work.

## Product Purpose

VibeCode is an AI-powered browser-based code editor with integrated chat, a live preview runtime, project management, and a marketplace for installable skills, templates, and tools. Success looks like: a developer opens it, describes what they want to build, and has a working project in minutes.

## Brand Personality

Sharp, fast, confident. Tool-native and decisive. The interface earns trust through precision, not decoration. Like Linear or Raycast: opinionated, fast, zero noise.

## Anti-references

- Generic SaaS cream: off-white backgrounds, Inter everywhere, purple-blue gradient CTAs, three-column feature card grids
- Overly corporate: navy + gold, dense data tables with no personality, enterprise grey
- AI startup cliché: glassmorphism as default, neon-on-black, "neural" blob aesthetics, gradient text everywhere
- GitHub clone: same dark sidebar + file tree + diff view aesthetic, grey-on-grey flatness

## Design Principles

1. **Tool disappears into the task.** Every design decision is tested by whether it helps users code faster, not whether it looks impressive.
2. **Confidence through precision.** Sharp edges, exact spacing, deliberate color. Fuzzy layouts and timid palettes signal uncertainty.
3. **Speed is a feature.** Transitions at 150–250 ms on product surfaces. No page-load choreography. Users are in flow.
4. **Earn the brand moment.** The landing page and marketplace are brand surfaces and may use more expressive color and typography. App surfaces stay restrained.
5. **Practice what you preach.** A code editor should look like it was built with care. Pixel-perfect alignment, real states, no broken interactions.

## Accessibility & Inclusion

WCAG AA minimum. Respect `prefers-reduced-motion`. All interactive elements keyboard-navigable with visible focus indicators. No color as the sole state indicator.
