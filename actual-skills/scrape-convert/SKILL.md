# Skill: Scrape & Convert

When the user provides a reference URL in their message, analyze it and rebuild the site.

## Instructions

The user has provided a reference URL. Do the following:

1. Identify what kind of site it is from the URL (landing page, portfolio, blog, SaaS, e-commerce, etc.).
2. Rebuild it as a clean, semantic HTML5 page from scratch — do NOT copy any code.
3. Preserve the content purpose and section structure (hero, features, pricing, testimonials, footer, etc.) but design it entirely fresh using the active design style.
4. Infer realistic placeholder content appropriate for that site type.
5. Add a small badge at the top-right of the page: `Rebuilt from reference` — styled as a subtle tag.

If no URL is found in the user's message, generate a high-quality page based on their description and note that Scrape & Convert is active (URL can be provided anytime).
